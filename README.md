## 💡 Overview

**MineNime** adalah aplikasi streaming anime ringan dan modern yang dibangun menggunakan perpaduan **Sketchware (Android WebView Native Wrapper)** serta **Vanilla HTML, CSS, dan JavaScript Native**. Dilengkapi dengan pemutar video custom berestetika warna ala Crunchyroll dan kontrol *overlay* terinspirasi dari Apple visionOS untuk memberikan pengalaman menonton anime yang responsif, cepat, dan interaktif.

---

## ✨ Features

- **Custom Video Player:** Desain UI pemutar video modern berestetika khas Crunchyroll dengan kontrol visionOS glassmorphism.
- **Fast & Lightweight:** Performa super cepat tanpa framework berat, murni menggunakan Vanilla JS, HTML, dan CSS.
- **Android App Support:** Berjalan mulus sebagai aplikasi Android native APK via Sketchware WebView engine.
- **Search & Filter:** Pencarian anime instan berdasarkan judul, genre, maupun status tayang.
- **Episode List & Server Switcher:** Navigasi episode mudah dan pilihan multi-server pemutaran video.
- **Responsive UI:** Tampilan fleksibel yang menyesuaikan berbagai ukuran layar (HP Android, Tablet, hingga Desktop).

---

## 👩‍💻 Tech Stack

- **HTML5 & CSS3**: Struktur antarmuka dan styling kustom berestetika modern.
- **JavaScript (Native/Vanilla)**: Logika aplikasi, fetching data episode, dan kontrol player interaktif.
- **Sketchware**: Modul pembangun aplikasi Android berbasis Java/WebView untuk merender web app menjadi APK.
- **Custom Player API**: Integrasi pemutar media HTML5 kustom.

---

## 📦 Getting Started

- **Web Browser** (Google Chrome, Firefox, atau Edge) untuk pengujian tampilan web.
- **Sketchware Pro / Revolution** (di perangkat Android) jika ingin melakukan *compile* menjadi file `.apk`.
- Editor kode seperti **VS Code** untuk mengedit file web (`index.html`, `style.css`, `app.js`).
